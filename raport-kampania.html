Metoda

To nie jest silnik zasad Arkham Horror LCG. Cztery skrypty w tools/: cards_data.py czyta liczby z plików kart, investigators.py koduje zdolności czwórki badaczy zdanie po zdaniu, scenario13_model.py i scenario2_model.py grają tysiące uproszczonych rozgrywek (efekty kart spotkań zakodowane z cytatem, polityka graczy = lista priorytetów), campaign_model.py spina scenariusze, PD, traumy i ulepszenia. Talie graczy to profile starterów arkhamdb (średnie ikony, liczba broni, leczenie); karty nie są zagrywane.

Powtórzenie

cd D:/arkham/Arkham
set PYTHONHASHSEED=0
set ARKHAM_PROFILES=custom          # własna ekipa; bez zmiennej: arkhamdb
python tools/custom_investigators.py build
python tools/scenario13_model.py values          # tabela wartości z kart
python tools/scenario13_model.py sim 1 --games 1500
python tools/scenario2_model.py sim --games 1500 --variant A
python tools/scenario2_model.py sim --games 1500 --variant B
python tools/scenario13_model.py sim 3 --games 600
python tools/scenario13_model.py sim 3 --games 600 --tweak GONIEC_DMG=0
python tools/scenario13_model.py sim 3 --games 600 --tweak KOR_START=1     # czesciowy sukces
python tools/scenario13_model.py sim 3 --games 600 --tweak KOZA_SELF_HEAL=0
python tools/scenario13_model.py sim 3 --games 600 --tweak LOC_DOOM_COUNTS=0
python tools/campaign_model.py run --variant A --campaigns 400
python tools/campaign_model.py narrate --variant A --seed 7
python tools/campaign_model.py xp
python tools/arkham_cards.py lint .
