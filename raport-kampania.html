Werdykt

Scenariusz 1 jest grywalny i ciasny w dobrym sensie. Własna ekipa wygrywa 78% gier, talie startowe z arkhamdb 68%. Jedyna porażka to zegar (15 zagłady), o którym rozstrzyga Pertraktacja int(4) w Obozie ocalałych i to, jak szybko las odsłania Obóz. Kart nie brakuje. Scenariusz 2 jest grywalny w obu wariantach. Wariant A (Arcykapłan) 76% / 71%, wariant B (Lewiatan) 45% / 35%. B przegrywa się przez wykrwawienie ekipy, nie przez zegar. Komplet kart, Strażnik Śluzy i atuty fabularne są na miejscu.

Scenariusz 3 nie jest gotowy. Ekipa bez doświadczenia wygrywa 7–8%, ekipa po dwóch scenariuszach z ulepszeniami 28–36%. Trzy rzeczy to blokują: Gońce, którzy po każdym dotarciu do celu zadają całej grupie 4 obrażenia i wracają do talii (średnio 28 obrażeń na grę; bez tego zdania wynik skacze do 64%), Czarna Koza z quantity 2 i grupą spotkań (autor: ma być odłożona do Aktu 5 — karta wciąż mówi inaczej) oraz Obłąkany Student, który samym rozstawieniem spacza Ostrów Tumski. Do tego zero punktów doświadczenia za cały scenariusz.

Kampania: komplet trzech zwycięstw w 25% (A) / 19% (B) kampanii własnej ekipy, 32% / 26% ekipy arkhamdb. Trójka jest najtrudniejsza i jako jedyna nic nie daje.

Metoda

To nie jest silnik zasad Arkham Horror LCG. Cztery skrypty w tools/: cards_data.py czyta liczby z plików kart, investigators.py koduje zdolności czwórki badaczy zdanie po zdaniu, scenario13_model.py i scenario2_model.py grają tysiące uproszczonych rozgrywek (efekty kart spotkań zakodowane z cytatem, polityka graczy = lista priorytetów), campaign_model.py spina scenariusze, PD, traumy i ulepszenia. Talie graczy to profile starterów arkhamdb (średnie ikony, liczba broni, leczenie); karty nie są zagrywane.

Powtórzenie

cd D:/arkham/Arkham
set PYTHONHASHSEED=0
set ARKHAM_PROFILES=custom          # własna ekipa; bez zmiennej: arkhamdb
python tools/custom_investigators.py build
python tools/scenario13_model.py values          # tabela wartości z kart
python tools/scenario13_model.py sim 1 --games 1500
python tools/scenario2_model.py sim --games 1500 --variant A
python tools/scenario2_model.py sim --games 1500 --variant B
python tools/scenario13_model.py sim 3 --games 600
python tools/scenario13_model.py sim 3 --games 600 --tweak GONIEC_DMG=0
python tools/scenario13_model.py sim 3 --games 600 --tweak KOZA_IN_DECK=1
python tools/scenario13_model.py sim 3 --games 600 --tweak AKT_DOOM=0
python tools/campaign_model.py run --variant A --campaigns 400
python tools/campaign_model.py narrate --variant A --seed 7
python tools/campaign_model.py xp
python tools/arkham_cards.py lint .

Selftesty: python tools/cards_data.py --selftest, python tools/investigators.py, python tools/scenario2_model.py --selftest, python tools/scenario13_model.py --selftest, python tools/campaign_model.py --selftest. Zmiany w narzędziach są w drzewie roboczym, niezacommitowane.
